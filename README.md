# CertifPlus - Secure Certification Web Service

A Python-based Web Service demonstrating secure electronic document delivery, authentication, and cryptographic verification. This project was developed as part of a University course on ICT Security (Sécurité des Usages TIC) and has been refactored for portfolio demonstration.

## Key Features
*   **Steganography & AEAD Encryption:** Hides sensitive diploma data (JWT + Timestamp) inside the image pixels using LSB (Least Significant Bit) steganography, encrypted with AES-GCM for confidentiality and integrity.
*   **Cryptographic Verification:** Generates a QR code containing an Elliptic Curve (ECC/ES256) signed JSON Web Token (JWT) to mathematically prove the document's authenticity.
*   **External Timestamping:** Integrates with FreeTSA (`freetsa.org`) to embed a trusted, verifiable timestamp into the hidden data.
*   **Mock SSO Authentication:** Simulates a CAS (Central Authentication Service) login flow. 
*   **TLS/TCP Proxy:** Designed to sit behind a `socat` reverse proxy to demonstrate secure HTTPS communication using a local PKI.

## Prerequisites

Before running this project, ensure you have the following system dependencies installed (Linux/Debian-based):

```bash
# Required for image processing and QR Code scanning
sudo apt-get update
sudo apt-get install imagemagick libzbar-dev socat
```
## Installation & Setup
# Clone the repository and navigate to it:

```bash
git clone [https://github.com/TheoBar418/Projet_CertifPlus.git]
cd Projet_CertifPlus
```
# Set up the Python Virtual Environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
# Configure Environment Variables:
Create a .env file based on the provided example:

```bash
cp .env.example .env
```
(Edit the .env file to set your own 32-character AES-GCM key and secret cookie).

# Generate the Local PKI (Public Key Infrastructure):
This script generates the necessary Elliptic Curve certificates for TLS and JWT signing.

```bash
chmod +x generate_pki.sh
./generate_pki.sh
```
# Usage
To test the application properly, you need to run the Python backend and the TLS proxy simultaneously in two different terminal windows.

Terminal 1: Start the Web Service (HTTP)

```bash
source .venv/bin/activate
python3 main.py
```
(You can test the service at this step at: http://localhost:8080)

Terminal 2: Start the TLS Proxy (HTTPS)

```bash
socat openssl-listen:9000,fork,cert=PKI/bundle_serveur.pem,cafile=PKI/ecc.ca.cert.pem,verify=0 tcp:127.0.0.1:8080
```
Accessing the Application:
Open your browser and navigate to: https://localhost:9000
(Note: Your browser will display a security warning because the certificate is signed by the local CA generated in Step 4. You can safely bypass this for local testing).
